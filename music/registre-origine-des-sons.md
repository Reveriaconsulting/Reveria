# Astrellia (anciennement RevLoop) — Registre d'origine des sons

Vérifié le 28/10/2026, à la source de chaque projet. Ce registre est la preuve demandée par Apple (règle 5.2.1) : chaque son de l'app est soit créé pour Astrellia, soit sous une licence qui autorise l'usage commercial.

## Résumé

- **18 sons de synthèse** : fabriqués par le code d'Astrellia (oscillateurs Web Audio, aucun enregistrement). Créés pour Astrellia par Reveria Consulting.
- **61 instruments enregistrés** : tous issus de projets publics en **CC0 1.0** (domaine public volontaire) ou en **domaine public**. Usage commercial autorisé, modification autorisée, aucune mention d'auteur obligatoire.
- **Sons de l'utilisateur** (sampleur) : enregistrés ou importés par l'utilisateur, gardés sur son appareil. Il en est responsable (à écrire dans les conditions d'utilisation).
- **Preuves** : copie de chaque licence ou page source dans le dossier `licences-sons/`.

## Ce que permettent ces licences

- **CC0 1.0** : l'auteur renonce à tous ses droits, dans le monde entier. On peut copier, modifier, vendre, sans demander ni citer. Texte : https://creativecommons.org/publicdomain/zero/1.0/
- **Domaine public** (piano à queue) : échantillons publiés en domaine public par Akai au début des années 2000, selon le dépôt source.

## Point à surveiller

- **Piano à queue** (`piano`) : la mention « domaine public » vient du dépôt sfzinstruments, pas d'un document d'Akai. C'est la preuve la plus faible du registre. Solution sûre si besoin : le **Piano de concert** (`piano-steinway`, VCSL, CC0) peut le remplacer.
- **Noms de marques** : fait le 28/10/2026. Les noms affichés ne contiennent plus de marque (Steinway, DX7, TX81Z, Juno retirés ; les identifiants internes restent inchangés).

## Comment ces sons ont été récupérés

Par les scripts du dossier `logiciel/outils/` (`telecharger_sons.py`, `telecharger_lot2.py`, `telecharger_lot3.py`) : ils téléchargent les sons depuis les adresses ci-dessus, les raccourcissent et les compressent (OGG ou AAC). Le premier refuse tout son dont la licence n'est pas CC0.
